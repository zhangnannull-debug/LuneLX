| 项 | 值 |
|---|---|
| JDK | 21 |
| Android SDK | platform 37 / build-tools 37.0.0 |
| Gradle | 9.7.1（wrapper 自带） |

```bash
./gradlew :app:assembleDebug          # 产物 app/build/outputs/apk/debug/Lune-debug.apk
./gradlew :app:testDebugUnitTest      # 34 个单测
node tools/preload-check.js           # 脚本桥接层回归（不需要 Android 工具链），期望 6/6
```

### 三个环境坑

1. **路径含中文 / 非 ASCII** → AGP 直接拒绝构建（`Your project path contains non-ASCII characters`）。
   解法：在 **Gradle 用户目录**（`~/.gradle/gradle.properties`）里加 `android.overridePathCheck=true`，
   **不要**写进项目自己的 `gradle.properties`。
2. **CI / 沙箱只能写工作区** → 把 `GRADLE_USER_HOME`、`TMP`/`TEMP` 都指到可写目录；
   另外 `ANDROID_PREFS_ROOT` 与 `ANDROID_USER_HOME` **不能同时设**且不一致，AGP 会报冲突，只设后者。
3. **`gradle.properties` 里的 `android.aapt2FromMavenOverride`** 曾经写死过一个容器内路径，
   在普通桌面上一构建就报一句很难懂的 AAPT2 错误 —— 已注释掉，别再加回来。

## 2. 真机调试经验

- **抓崩溃**：`adb logcat -c` → 复现 → `adb logcat -d -s AndroidRuntime:E`。别靠截图猜。
- **读界面**：`adb shell uiautomator dump /sdcard/x.xml` + `adb pull`，解析 `bounds` 再 `input tap`。
  两个坑：
  - **播放中 uiautomator 拿不到 idle**（可视化动画一直在画）→ 先 `cmd media_session dispatch pause`，
    或临时把三个动画缩放设成 0（用完记得改回 1）。
  - **设置页会记住上次滚动位置**，固定坐标不可靠 —— 按文字找坐标再点。
- **看落盘的设置值**：`adb shell run-as com.lunelx.music cat shared_prefs/lune_settings.xml`。
- **二进制文件别走 PowerShell 管道**：`adb shell cat > file` 会被文本编码破坏。
  用 `cmd /c "adb exec-out run-as <pkg> cat <path> > local"` 或 `adb exec-out screencap -p > x.png`。
- **推测试脚本**：`adb push x.js /data/local/tmp/` →
  `adb shell run-as com.lunelx.music cp /data/local/tmp/x.js files/lx_scripts/x.js`
  （别用 `>` 重定向，会落到外层 shell）。
- 本项目在 **Xiaomi 25113PN0EC / Android 16 / API 36 / arm64-v8a** 上验证。

## 3. 几个必须知道的设计约束

1. **uid 是唯一标识**：本地 `local:<MediaStoreId>`，在线 `lx:<source>:<songmid>`。
   在线歌曲 `id` 恒为 0，任何跨模块查找都必须用 `uid`（见 `tools/SongUid.kt`）。
   持久化层的 key（收藏 `song_overrides.songUid`、统计 `SONG_<uid>`、AI 偏好、歌词文件名）也全部是 uid。
2. **在线歌曲是易失对象**：不在 MediaStore 里，进程退出就没了。所以 Room 里存 `Song` 的 JSON 快照
   （`song_overrides.meta` / `playback_stats.meta`），重启后按 uid 重建；队列也把在线歌快照一并保存。
3. **Gson 不使用 Kotlin 默认值**：给持久化数据类加字段时，老 JSON 反序列化会得到 `null`。
   新增字段要么可空 + `orEmpty()`，要么在读取处兜住（踩过 `SavedPlaybackState.queueOnlineSongs` 的坑）。
4. **Room 3 的迁移 API 变了**：`Migration.migrate(connection: androidx.sqlite.SQLiteConnection)` 是
   `suspend` 的，且 `SQLiteConnection` 只有 `prepare(sql)`，执行语句是 `prepare(...).use { it.step() }`。
   迁移 SQL 必须与 `app/schemas/…/<version>.json` 里导出的建表语句一致。
5. **播放上下文 `activeCategory` 要写合法分区 id**（`ONLINE`/`ALL`/…）。
   写成临时字符串（如 `"在线发现"`）会被"分区被隐藏就清空播放"的判断误判，导致
   `currentSong` 被清空但服务还在响。

## 4. 在线链路要点（都实测过）

| 环节 | 关键点 |
|---|---|
| 搜索 | 客户端直连平台接口（`lx/search/LxBuiltinSearch.kt`）；脚本只负责 `musicUrl` |
| 歌词 | 网易云含翻译；酷狗要两步（krcs→download）再 base64；酷我三个入口全封 |
| 取流 | 必须走本地代理：防盗链 Referer/Cookie、`http→https` 跨协议重定向（Android `HttpURLConnection` 不跟）、403 重解析（先失效缓存） |
| 下载 | 复用代理地址 → 临时文件 → jaudiotagger 写 APIC/USLT → MediaStore（`IS_PENDING`） |
| 榜单 | 酷狗 `mobilecdn` 只能走 **http**（证书是 `*.cdn.myqcloud.com`，https 会 SSL 校验失败）；`rank/song` 必须带 `version=8000` 才是完整榜单；歌曲封面字段是 `album_sizable_cover` |

## 5. 已知问题（按优先级）

| 优先级 | 问题 | 说明 |
|---|---|---|
| 高 | QQ 音乐播不了 | 特定脚本的 tx 分支返回 `/share/ceshi/None`，代理拿到 404 —— 脚本侧问题 |
| 中 | 在线歌不能进播放列表 | `playlist_songs` 仍按 MediaStore id 存，在线歌会互相顶掉；UI 已对在线歌隐藏该入口 |
| 中 | 酷我 / 咪咕「发现」无数据 | 两家榜单接口要登录态（酷我匿名 `The request is illegal!`，咪咕「路由请求不支持」） |
| 中 | 酷我歌词缺失 | 三个歌词入口均返回 `TP=ERROR REQUEST` |
| 低 | 下载无进度/队列/续传 | 只有转圈 + 完成提示 |
| 低 | 在线播放偶发「没声但状态仍播放」 | 已加假活看护（位置 6 秒不动 → 重解析 + seek；再不动 → 跳下一首），根因仍在跟进 |
